# INeedBio Classroom: คู่มือติดตั้ง

ระบบเว็บเรียนที่ใช้ Google Sheet เป็นฐานข้อมูล ในแพ็กนี้มี 2 ไฟล์หลัก

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `backend/Code.gs` | หลังบ้าน (Google Apps Script) มีระบบสมัคร/OTP/login, คอร์ส, สลิป, หลังบ้านแอดมิน และอีเมลทั้งหมด |
| `frontend/index.html` | หน้าเว็บทั้งหมดรวมไว้ในไฟล์เดียว เอาไปวางบนโฮสต์ไหนก็ได้ |

---

## 1. ติดตั้งหลังบ้าน (ประมาณ 10 นาที)

1. ล็อกอิน **ineedbio1803@gmail.com** แล้วเข้า https://script.google.com → **New project** แล้วตั้งชื่อว่า `INeedBio API`
2. ลบโค้ดเดิมทิ้ง วางโค้ดทั้งหมดจาก `Code.gs` แล้วกด Save
3. เลือกฟังก์ชัน **`setup`** ที่แถบด้านบน แล้วกด **Run** และกดอนุญาตสิทธิ์ (Sheets, Drive, Gmail)
   - ระบบจะสร้างไฟล์ **INeedBio DB** (10 แท็บ) และโฟลเดอร์ **INeedBio Slips** ใน Drive ให้เอง ส่วนโฟลเดอร์รูปโปรไฟล์และไฟล์ประกอบบทเรียนจะถูกสร้างตอนอัปโหลดครั้งแรก
   - ลิงก์ของ Sheet อยู่ใน Execution log
4. กด **Deploy → New deployment → เลือกประเภท Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้ว **คัดลอก URL ที่ลงท้ายด้วย `/exec`**
5. เลือกฟังก์ชัน **`installTriggers`** แล้วกด Run ระบบจะล้าง session ที่หมดอายุให้ทุกคืน

> ⚠️ **ทุกครั้งที่แก้โค้ด** ต้องกด Deploy → Manage deployments → ✏️ → Version: **New version** → Deploy
> ถ้าไม่ทำ เว็บจะยังเรียกโค้ดเวอร์ชันเก่าอยู่ ส่วน URL ยังใช้อันเดิมได้

## 2. ติดตั้งหน้าเว็บ

1. เปิด `frontend/index.html` แล้วหาบรรทัดนี้
   ```js
   var API_URL = 'PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE';
   ```
   วาง URL จากข้อ 1.4 ลงไปแทน
2. อัปโหลดไฟล์นี้ขึ้นโฮสต์ เช่น Vercel หรือ Netlify แล้วผูกกับโดเมน ineedbio.shop
   - ถ้าจะใช้ Vercel ให้ใส่ไฟล์ไว้ในโฟลเดอร์ แล้วตั้งชื่อไฟล์เป็น `index.html`
   - ถ้ายังไม่มีโฮสต์ ใช้ Netlify Drop (https://app.netlify.com/drop) โดยลากโฟลเดอร์ไปวางได้เลย

## 3. ตั้งตัวเองเป็นแอดมิน

1. เปิดเว็บแล้วสมัครสมาชิกด้วยอีเมลของคุณตามขั้นตอนปกติ (กรอก OTP ให้เสร็จ)
2. กลับไปที่ Apps Script แล้วแก้บรรทัดล่างสุดของไฟล์ชั่วคราว ให้มีฟังก์ชันนี้
   ```js
   function runOnce() { makeAdmin('อีเมลของคุณ@gmail.com'); }
   ```
   เลือก `runOnce` แล้วกด Run จากนั้นลบฟังก์ชันนี้ออกได้เลย
3. รีเฟรชหน้าเว็บ จะเห็นเมนู **หลังบ้าน** ขึ้นมา
   - แอดมินคนต่อไป ตั้งได้จากหลังบ้าน → ทะเบียนนักเรียน → **แก้ไข** → **ตั้งเป็นแอดมิน** โดยไม่ต้องเข้าโค้ด

## 4. เริ่มใช้งาน

1. **หลังบ้าน → ตั้งค่า:** ใส่เบอร์พร้อมเพย์ ชื่อบัญชี IG และอีเมลที่จะรับแจ้งเตือนเมื่อมีคำขอใหม่
2. **หลังบ้าน → คอร์สและบทเรียน → + คอร์สใหม่:** ตั้งสถานะเป็น "ฉบับร่าง" ไว้ก่อน
3. เปิดคอร์ส แล้วเพิ่มตอนทีละตอนโดยแปะลิงก์ YouTube ลงไป ถ้าจะย้ายตอน ให้ลาก ⋮⋮ เพื่อเรียงใหม่
4. พอเนื้อหาพร้อม ให้แก้ไขคอร์สเป็น **"เปิดขาย"** คอร์สจะขึ้นบนหน้าแรกภายใน 5 นาที

### การตั้งค่าคลิปใน YouTube

- ตั้ง Visibility เป็น **Unlisted**
- ต้องเปิด **Allow embedding** ไว้ (เปิดเป็นค่าเริ่มต้นอยู่แล้ว) ถ้าปิด คลิปจะเล่นบนเว็บไม่ได้

### หน้าแนะนำคอร์ส

เข้าหลังบ้าน → คอร์สและบทเรียน → เปิดคอร์ส → **แก้ไขข้อมูลและหน้าแนะนำ** จะกรอกคลิปแนะนำ จุดเด่น คอร์สนี้เหมาะกับใคร ผู้สอน และคำถามที่พบบ่อยได้ ช่องไหนเว้นว่าง ส่วนนั้นจะไม่แสดงบนหน้าเว็บ ลิงก์ของหน้าแนะนำคือ `ineedbio.shop/#/course/รหัสคอร์ส` เอาไปแปะใน IG ได้เลย

**ข้อความหน้าแรก:** แก้หัวข้อใหญ่และข้อความใต้หัวข้อได้ที่ หลังบ้าน → ตั้งค่า → หน้าแรก
**ราคาเต็ม (ขีดฆ่า):** ใส่ในช่อง "ราคาเต็ม" ของคอร์ส เช่น 1090 หน้าเว็บจะแสดงเป็น "จาก 1,090 บาท" แล้วตามด้วยราคาขาย

> ถ้าติดตั้งเวอร์ชันก่อนหน้าไว้แล้ว: ดูหัวข้อ **อัปเกรดจากเวอร์ชันก่อน** ด้านล่าง


### ผลงานนักเรียน (Hall of fame)

เข้าหลังบ้าน → **ผลงานนักเรียน** → **+ เพิ่มน้อง** แล้วกรอกชื่อเล่น ปี สาขา โรงเรียน ศูนย์ และรีวิว จากนั้นกด "อัปโหลดรูป" ระบบจะเก็บรูปไว้ในโฟลเดอร์ **INeedBio Public Images** บน Drive ให้เอง โฟลเดอร์นี้ตั้งเป็นเปิดดูได้สำหรับทุกคนที่มีลิงก์ แยกจากโฟลเดอร์สลิปซึ่งยังเป็นส่วนตัว

ข้อมูลที่เพิ่มจะขึ้นใน 3 ที่
- **หน้าแรก:** ส่วน Hall of fame
- **หน้า "ผลงานน้องๆ":** รวมรีวิวทั้งหมด
- **หน้าคอร์ส:** รีวิวของน้องที่ติดสาขาเดียวกับคอร์สนั้น

บนเว็บจะแสดงแค่ชื่อเล่น โรงเรียน และศูนย์ ไม่แสดงนามสกุล ควรขออนุญาตน้องก่อนใช้รูปและรีวิว

ปุ่ม "อัปโหลดรูป" ใช้กับรูปปกคอร์สและรูปผู้สอนได้ด้วย


### ข้อมูลตอนสมัคร / ข้อตกลงการใช้งาน

- **สมาชิกทุกคน:** ต้องกรอกคณะและมหาวิทยาลัยในฝัน
- **เด็กซิ่ว:** ถ้าเลือกระดับชั้น "จบ ม.6 แล้ว" หรือ "อื่นๆ" ต้องกรอกคณะและมหาวิทยาลัยที่เรียนอยู่ตอนนี้ด้วย
- **ยอมรับข้อตกลงก่อนสมัคร:** ต้องติ๊กยอมรับข้อตกลงการใช้งานและนโยบายความเป็นส่วนตัวก่อน ระบบบันทึกเวอร์ชันข้อตกลงและเวลาที่ยอมรับไว้ในแท็บ Users
- **หน้าเว็บ:** ข้อตกลงอยู่ที่ `#/terms` และนโยบายอยู่ที่ `#/privacy` มีลิงก์ท้ายเว็บ
- **แก้ข้อความ:** แก้ได้ที่ หลังบ้าน → ตั้งค่า
- **ภาพรวมหลังบ้าน:** แสดง "คณะในฝันยอดนิยม" และจำนวนเด็กซิ่ว

> ข้อความข้อตกลงและนโยบายเป็นแบบทั่วไป ควรให้ผู้รู้กฎหมายตรวจก่อนเปิดใช้จริง โดยเฉพาะเรื่องการคืนเงิน

## ฟีเจอร์ที่ย้ายมาจากระบบ Next.js

ฟีเจอร์ทั้ง 6 อย่างนี้ย้ายมาจากระบบ Next.js (ineedposn-lms) โดยยังใช้ Google Sheet และ Drive เป็นที่เก็บข้อมูลเหมือนเดิม

### รูปโปรไฟล์
- นักเรียนเพิ่มรูปได้ตอนสมัคร (ไม่บังคับ) หรือที่หน้า **ข้อมูลส่วนตัว → รูปโปรไฟล์** รูปจะขึ้นที่มุมขวาบนและในหลังบ้าน
- ระบบย่อรูปให้เหลือไม่เกิน 512px ก่อนอัปโหลด แล้วเก็บในโฟลเดอร์ **INeedBio Avatars** บน Drive (เปิดดูได้เฉพาะคนที่มีลิงก์) พอเปลี่ยนหรือลบรูป รูปเก่าจะถูกย้ายไปถังขยะ

### ทะเบียนนักเรียน (หลังบ้าน → ทะเบียนนักเรียน)
- **ตาราง:** 1 แถวคือนักเรียน 1 คนกับคอร์ส 1 คอร์ส กรองตามคอร์ส ชั้น หรือสถานะชำระเงินได้ และค้นหาด้วยชื่อ โรงเรียน เบอร์ หรืออีเมลได้
- **แก้ในตาราง:** เปลี่ยนสถานะชำระเงิน (ชำระแล้ว / รอตรวจสอบ / ยังไม่ชำระ) หรือเขียนบันทึก แล้วกด **บันทึกการเปลี่ยนแปลง** ครั้งเดียว ถ้าจะออกจากหน้าโดยยังไม่บันทึก ระบบจะเตือนก่อน
  - เปลี่ยนเป็น "ชำระแล้ว": นักเรียนเข้าเรียนได้ทันทีและได้อีเมลแจ้ง
  - เปลี่ยนเป็น "ยังไม่ชำระ": ปิดสิทธิ์เรียน นักเรียนส่งสลิปใหม่ได้
- **+ เพิ่มนักเรียน:** ใช้กับนักเรียนที่สมัครทางช่องทางอื่น
  - อีเมลใส่หรือไม่ใส่ก็ได้ ถ้าใส่ นักเรียนเข้าเว็บ กด "ลืมรหัสผ่าน" เพื่อตั้งรหัสเอง แล้วเข้าเรียนได้เลย (อีเมลแจ้งอนุมัติจะบอกขั้นตอนนี้ให้)
  - ติ๊ก "นักเรียน สอวน." เพื่อเพิ่มชื่อลงหน้าผลค่ายด้วย
- **แก้ไข:** แก้ข้อมูล เพิ่มคอร์ส ล้างอุปกรณ์ ตั้งเป็นแอดมิน ระงับบัญชี หรือลบนักเรียน
  - การลบจะลบบัญชี สิทธิ์เรียน และความคืบหน้า
  - รูปสลิปใน Drive และข้อมูลในหน้าผลค่ายยังเก็บไว้
- **ดาวน์โหลด / นำเข้า JSON:** ใช้รูปแบบเดียวกับระบบ Next.js
  - อีเมลที่มีบัญชีอยู่แล้วจะถูกข้าม
  - คอร์สจับคู่จากชื่อคอร์ส ถ้าไม่เจอ ระบบจะเก็บชื่อคอร์สเดิมไว้ในช่องบันทึก
  - การนำเข้าไม่ส่งอีเมลหานักเรียน

> นักเรียนที่แอดมินเพิ่มเองยังไม่ได้กดยอมรับข้อตกลงการใช้งาน ถ้าจำเป็น ควรให้นักเรียนยืนยันผ่านช่องทางอื่น

### ผลค่าย สอวน. (หลังบ้าน → ผลค่าย สอวน.)
- **ภาพรวม:** นับจำนวนตามผลค่าย 1 และแยกตาม 17 ศูนย์ กดการ์ดศูนย์เพื่อกรองได้
- **แก้ในตาราง:** เปลี่ยนผลหรือบันทึกในตารางได้เลย ระบบบันทึกทันที
- **+ ผลงาน:** ปุ่มนี้ขึ้นเมื่อนักเรียน "ผ่านค่าย 1" กดแล้วจะเปิดฟอร์มผลงานนักเรียนพร้อมข้อมูลที่กรอกไว้ให้แล้ว
- **นำเข้า JSON:** เลือกได้ว่าจะเพิ่มต่อท้ายหรือแทนที่ทั้งหมด ไฟล์จากระบบ Next.js ใช้ได้เลย
- **ข้อมูลในแท็บ `Camp`:** เห็นเฉพาะแอดมิน

### บัญชีรับเงินแยกตามคอร์ส
- **ตั้งค่า:** แก้ไขคอร์ส → ใส่เบอร์หรือเลขพร้อมเพย์และชื่อบัญชีของคอร์สนั้น
- **รูป QR ของตัวเอง:** อัปโหลดรูป QR จากแอปธนาคารได้ ระบบจะแสดงรูปนั้นแทน QR ที่สร้างเอง พร้อมเบอร์พร้อมเพย์ไว้ใต้รูป
- **ช่องว่าง:** ถ้าไม่ใส่ ระบบจะใช้บัญชีกลางใน หลังบ้าน → ตั้งค่า

### ไฟล์ประกอบบทเรียน
- **อัปโหลด:** ในฟอร์มเพิ่มหรือแก้ตอน กด **อัปโหลดไฟล์** ได้ รองรับ PDF, Word, PowerPoint, Excel, ZIP และรูป ไฟล์ละไม่เกิน 10 MB
- **หลายไฟล์:** ใส่ได้หลายไฟล์ บรรทัดละ 1 ไฟล์ในรูปแบบ `ชื่อไฟล์ | ลิงก์` แปะลิงก์ Google Drive เองก็ได้
- **ที่เก็บ:** ไฟล์อยู่ในโฟลเดอร์ **INeedBio Lesson Files** (เปิดได้เฉพาะคนที่มีลิงก์) หน้าเว็บส่งลิงก์ให้เฉพาะคนที่มีสิทธิ์เรียนคอร์สนั้น

### Design Studio (หลังบ้าน → Design Studio)
- **บล็อก:** บล็อกโปรโมตบนหน้าแรกมี 4 แบบ คือ Hero, การ์ดคอร์ส, แถวฟีเจอร์ และแบนเนอร์
- **แก้ไข:** เลือกสีพื้นและสีตัวอักษรได้ อัปโหลดรูปได้ ใส่ลิงก์ได้ ตัวอย่างอัปเดตตามที่พิมพ์
- **เรียงลำดับ:** ลาก ⋮⋮ หรือกด ↑ ↓ (บนมือถือใช้ปุ่มลูกศร)
- **ซ่อน:** กด "ซ่อน" แล้วบล็อกจะหายจากหน้าแรกโดยไม่ต้องลบ หน้าเว็บอัปเดตภายใน 5 นาที

### อัปเกรดจากเวอร์ชันก่อน
1. เปิดโปรเจกต์ Apps Script เดิม ลบโค้ดใน `Code.gs` แล้ววางตัวใหม่ทั้งไฟล์ กด Save
2. รัน `setup()` อีกครั้ง ข้อมูลเดิมไม่หาย ระบบจะเพิ่มแท็บ `Camp` และ `Blocks` และเพิ่มคอลัมน์ใหม่ในแท็บ Users กับ Courses ให้เอง (ถ้าลืมรัน ระบบก็เพิ่มให้ตอนใช้งานครั้งแรก)
3. กด Deploy → Manage deployments → ✏️ → Version: **New version** → Deploy
4. เปลี่ยน `frontend/index.html` บนโฮสต์เป็นไฟล์ใหม่ อย่าลืมใส่ `API_URL` เดิมกลับไป
5. ถ้าจะย้ายข้อมูลจากระบบ Next.js ให้กด "ดาวน์โหลด JSON" ในหน้าทะเบียนนักเรียนและหน้าผลค่ายของระบบเดิม แล้วกด "นำเข้า JSON" ในหน้าเดียวกันของระบบนี้

## 5. การทำงานของระบบ

- **สมัครสมาชิก:** ผู้สมัครกรอกข้อมูลแล้วได้ OTP ทางอีเมล ระบบจะบันทึกลงแท็บ `Users` ก็ต่อเมื่อกรอก OTP ถูก รหัสผ่านเก็บเป็นค่า hash ไม่เก็บรหัสจริง
- **ซื้อคอร์ส:** นักเรียนสแกน QR พร้อมเพย์ (ยอดตรงกับราคาคอร์ส) แล้วแนบสลิป ระบบเก็บสลิปไว้ใน Drive และอีเมลแจ้งแอดมิน
- **อนุมัติ:** แอดมินเข้าหลังบ้าน → คำขอเข้าเรียน → ตรวจสลิป → อนุมัติ นักเรียนได้อีเมลแจ้งและเข้าเรียนได้ทันที ถ้าจะปฏิเสธต้องใส่เหตุผล และนักเรียนส่งสลิปใหม่ได้
- **ห้องเรียน:** ระบบส่งรหัสคลิปให้เฉพาะคนที่ได้รับอนุมัติแล้ว มีลายน้ำอีเมลผู้เรียนวิ่งอยู่บนคลิป และติ๊ก "ดูจบ" เพื่อนับ % ได้
- **1 บัญชี = 1 เครื่อง:** ถ้า login จากเครื่องใหม่ เครื่องเก่าจะหลุดทันทีและขึ้นข้อความแจ้ง ถ้านักเรียนเปลี่ยนเครื่องแล้วมีปัญหา แอดมินกด "ล้างอุปกรณ์" ได้
- **สิทธิ์ดูคลิป:** ไม่มีวันหมดอายุ
- **เพิ่มสิทธิ์เอง:** ใช้เมื่อนักเรียนโอนผ่านช่องทางอื่น เข้าที่หลังบ้าน → คำขอเข้าเรียน → "+ เพิ่มสิทธิ์ให้ผู้ใช้เอง"

## 6. ข้อควรรู้

- **โควตาอีเมล:** Gmail ธรรมดาส่งอีเมลจาก Apps Script ได้ประมาณ **100 ฉบับต่อวัน** หน้าภาพรวมในหลังบ้านจะแสดงจำนวนที่เหลือ ถ้าเต็ม ผู้สมัครจะเห็นข้อความให้ลองใหม่พรุ่งนี้
- **คลิป Unlisted:** ถ้าลิงก์หลุด ใครมีลิงก์ก็ดูได้ ลายน้ำและการจำกัด 1 เครื่องช่วยลดความเสี่ยงได้ แต่กันไม่ได้ 100% ถ้าลิงก์หลุดจริง ให้อัปคลิปใหม่แล้วแก้ลิงก์ในหลังบ้าน
- **แก้ข้อมูลใน Sheet ตรง ๆ:** ทำได้ แต่ห้ามแก้แถวหัวตาราง (แถวที่ 1) หน้าเว็บอาจใช้เวลาถึง 5 นาทีกว่าข้อมูลใหม่จะขึ้น
- **ไฟล์ INeedBio DB:** แชร์ให้เฉพาะคนที่จำเป็นจริง เพราะในไฟล์มีข้อมูลนักเรียนทุกคน ทีมงานคนอื่นให้ทำงานผ่านหน้าหลังบ้านแทน
- **ระบบ OTP ตัวเดิม:** ระบบนี้มีสมัคร/OTP/ลืมรหัสผ่านครบในตัวแล้ว ให้ใช้แทนโปรเจกต์ OTP เดิมได้เลย

## 8. ลองเล่นก่อนติดตั้ง (ไม่บังคับ)

ดับเบิลคลิกเปิด `preview/demo.html` ในเบราว์เซอร์ได้เลย ไฟล์นี้รันหลังบ้านจำลองในเบราว์เซอร์ ข้อมูลทั้งหมดเป็นตัวอย่าง และจะหายเมื่อรีเฟรช
- **เข้าสู่ระบบ:** ตอนกดเข้าสู่ระบบจะมีปุ่มลัด "แอดมิน" และ "นักเรียน" ให้กด
- **OTP ตอนสมัคร:** ไม่มีการส่งอีเมลจริง เปิด Console แล้วพิมพ์ `__mock.outbox` เพื่อดูรหัส

ไฟล์นี้ใช้ดูอย่างเดียว ห้ามอัปโหลดขึ้นโฮสต์ ไฟล์ที่ใช้จริงคือ `frontend/index.html`
